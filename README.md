# GigFlow – Smart Leads Dashboard

A full-stack MERN dashboard application built for managing and tracking business leads with authentication, lead analytics, filtering, and CRUD operations.

## 🚀 Live Demo

### Frontend
https://smart-leads-frontend-v12m.onrender.com

### Backend API
https://smart-leads-dashboard-lmq7.onrender.com

## 📌 Features

### Authentication
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Persistent Login

### Lead Management
- Add New Leads
- View Leads
- Edit Lead Status
- Delete Leads
- Search Leads
- Filter Leads by Status

### Dashboard Analytics
- Dynamic Statistics Cards
- Lead Analytics Pie Chart
- Real-time Status Updates

### UI/UX
- Responsive Dashboard
- Modern SaaS-inspired UI
- Toast Notifications
- Search & Filter Functionality
